# Recon Toolkit

Suite ligera de automatizacion en Bash para reconocimiento de red y auditoria de puertos criticos (22, 80, 443).

## Uso rapido
```bash
chmod +x scanner.sh
./scanner.sh 192.168.1.0/24
```

## Seguridad (OPSEC)
Reportes y credenciales excluidos del control de versiones mediante .gitignore.
